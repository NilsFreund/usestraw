agent.ts 
import { connect } from "usestraw"

const phone = await connect(process.env.SIP_URL)

for await (const call of phone.incoming) {
  void call.accept(new TransformStream()) // callers hear themselves
}

The whole app

Put your voice agent where the TransformStream is, and it answers the phone. Calling out works like fetch, and every call says why it ended.

0.1 runs in Node 22.12 and up and speaks G.711. No SRTP, DTMF, hold or transfer yet; the browser comes next. All limits
